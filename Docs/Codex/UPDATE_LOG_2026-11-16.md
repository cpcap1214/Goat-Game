# Update log — 2026-11-16

本次提交對象：`cpcap1214/Goat-Game` 的 `main`。包含此分支先前尚未合併的主線房間更新，以及新的回放能力與視覺調整。

## 主線房間與舊關卡

- 保留開場；主線使用獨立 Room 1–3 與升降機過渡場景。
- 舊四關與 EchoFoothills 保留於 Debug Mode。
- 房間包含山羊雕像檢查點、隱形死亡區、草地／木製單向平台、Down+Jump 下穿、壓力板、限時／移動平台及升降機。
- 主線房間上方不再有撞頭邊界；山羊可以跳出畫面，相機仍受房間邊界限制。

## 新回放能力

- Debug Mode 分開提供 **06 Basic Replay** 與 **07 Upgraded Replay**。
- 長按 Q **0.5 秒**錄製／覆寫，最多 10 秒；放開起始長按不會結束錄製。
- 再按 Q 保存，世界以 5 倍速可視倒帶至錄影起點，不重載關卡。
- 玩家、箱子、移動平台、壓力板與門支援狀態還原；物件元件的 `affectedByRewind` 決定是否參與，不顯示遊戲內標籤。
- Q 播放；播放途中按 Q 從開頭正向重播，不替換記憶或重設本體位置。
- 殘影停在終點，仍可承載玩家或壓住踏板。
- 進階版：短按 Left Shift 切換正／倒帶；長按暫停殘影，放開沿原方向繼續。玩家與世界不會因此暫停。
- 基本版不接受 Shift 功能；`UnlockReplayUpgrade()` 提供後續道具解鎖入口，尚未指定正式關卡取得位置或跨房間存檔流程。

## 視覺與 UI

- 山羊頭上顯示錄影蓄力圓環。
- 錄影顯示加厚膠卷邊框、快速流動齒孔、0.16 秒由左向右淡入，以及暖色顆粒濾鏡。
- 回放進度條移至畫面底部、加厚，使用暖琥珀色與時間位置指示點；僅顯示進度，不支援拖曳跳轉。
- 軌跡更細淡，殘影與快速倒帶顏色統一為暖色；隱藏殘影平台的橫線。
- EchoFoothills 的 F 年代切換加入 0.36 秒鏡片動畫；過去視角使用細微暖色、顆粒與暗角，HUD 保持清晰。
